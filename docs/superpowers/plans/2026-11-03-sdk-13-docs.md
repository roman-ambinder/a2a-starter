# SDK package 13: Docs for product teams — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task by task, with every subagent on model `sonnet` (see "Execution notes" at the end). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the consumer docs site (DocFX, versioned on GitHub Pages) with the structure, page template, generated reference pages, sample index, machine-checked Phase 1 migration map, rewritten READMEs, and the checks that keep docs true (`eng/DocsLint`, widened `DocsTests`, `MigrationMapTests`, `ReadmeTemplateTests`, Vale), plus the `docs` CI job and publishing. Package 13 writes the shared pages (getting started, concepts, migration, policies, reference, troubleshooting); every other package writes its own guide pages into the places fixed here.

**Spec (binding):** `docs/superpowers/specs/2026-11-03-sdk-13-docs-design.md` ("the spec"; "§N" means its Design section N). Work plan: `docs/superpowers/specs/2026-11-03-sdk-00-work-plan.md` (O2, O3). Package map: `docs/superpowers/specs/2026-11-03-sdk-01-packaging-release-design.md` §1.

**Architecture:**
- Markdown in `docs/`, built by DocFX into `artifacts/docs/`; folder = URL. One `toc.yml` per section. Maintainer-only folders (`docs/superpowers/`, `docs/architecture/`, `docs/release/`) are excluded from the site.
- `eng/DocsLint` is a small .NET console tool that generates the drift-prone pages and checks the rules. Its rules are also run as tests, so `dotnet test` catches drift locally.
- DocFX includes pull every C# block over 5 lines from compiled projects in `samples/`.
- CI: a `docs` job on PRs that touch docs, samples or READMEs; a publish workflow for `master` → `/next/`; package 01's release `docs` hook job → `/v<major>.<minor>/` and `/latest`.

**Tech Stack:** .NET 10, DocFX 2.x (as a local dotnet tool), Vale (GitHub action, warning level), Mermaid diagrams, xUnit v3 for the docs tests, GitHub Pages (from a `gh-pages` branch). Versions: check nuget.org/GitHub for the newest stable; do not guess.

1. **Generated pages cannot drift:** changing an option default, an error code or a telemetry name without regenerating fails a test (Task 5).
