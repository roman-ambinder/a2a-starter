# SDK package 06: Multi-instance cluster layer, implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task by task. Every subagent runs on model `sonnet` (see "Execution notes" at the end). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A group of pods behaves like one A2A server. The store records which pod runs a task. Other pods forward cancel, subscribe and continue requests to that pod over authenticated internal HTTP. Leases (package 09) handle a pod that dies. There is no Redis or message bus. The four seams sit in the core, so a Redis backend can replace HTTP forwarding after 1.0. A single pod without `AddA2ACluster()` pays nothing.

**Spec (binding):** `docs/superpowers/specs/2026-11-03-sdk-06-cluster-design.md` (approved 2026-11-03, milestone M2, size XL). Where this plan and the spec disagree, the spec wins. Stop and report the conflict; do not pick one silently.

**Architecture:**
- **Core (`Ambinder.A2A.Server`, namespace `Ambinder.A2A.Server.Cluster`):** the core gets the seams `ITaskEventBus`, `TaskSubscription`, `ITaskRouter`, `TaskRoute`, `PeerInstance`, `ITaskForwarder` and `ClusterCallContext`. Its defaults are:
  - today's `TaskEventBroker`, made internal behind `ITaskEventBus`
  - `LocalTaskRouter`, which always answers "local" and reads nothing from the store

  `TaskManager` asks the router before cancel, subscribe and continuation, after it has loaded the task and checked owner and tenant.
- **`Ambinder.A2A.Cluster` (new):**
  - `AddA2ACluster()` and `A2AClusterOptions`
  - the instance (peer) cache and the store-backed `ClusterTaskRouter`
  - `HttpTaskForwarder`, with the durable cancel fallback
  - the internal endpoints on `InternalPort`
  - the `IClusterPeerAuthentication` seam
  - the streaming proxy
  - durable cancel polling, the `a2a-cluster` health check, and the graceful scale-down participant

  It does not depend on Azure.
- **`Ambinder.A2A.Cluster.Entra` (new):** `AddEntraPodAuthentication()`. It gets workload identity tokens for the agent's app ID URI and validates the app role `A2A.Cluster.Peer`.
- **Test-only:**
  - the `SharedKey` HMAC pod authentication (C6: it never ships)
  - the `ClusterTestHarness`
  - the in-process "fake Redis" backend (Goal 9)
  - a round-robin proxy for the TCK
  - a `kind` cluster host image

**Tech stack:** .NET 10, ASP.NET Core (Kestrel h2c listener, minimal APIs, `RequireHost`), `IHttpClientFactory` + `SocketsHttpHandler` (HTTP/2, `EnableMultipleHttp2Connections`), `System.Threading.Channels`, `System.Text.Json` source generation, `System.Diagnostics` (`ActivitySource`, `Meter`), `Microsoft.Extensions.Diagnostics.HealthChecks`, `Azure.Identity` (Cluster.Entra only), EF Core stores from package 05 (SQLite file, PostgreSQL with Testcontainers), `Microsoft.Extensions.TimeProvider.Testing`, xUnit v3, `Yarp.ReverseProxy` (test-only, for the TCK round-robin proxy), Kustomize and `kind`.

## Review focus (reviewers check these first)

1. **No check is skipped.** Routing happens inside `TaskManager`, after the receiving pod's full pipeline and after the owner and tenant check. The owner pod treats `IsForwarded` calls as tracing + handler only (09's B5 rule), and never forwards again (`HopCount`) (Tasks 3, 7).
2. **Existence is never revealed.** A forwarded call is made only after the receiving pod has loaded and authorized the task. A `409 not-runner` body names only an instance id, never task data (Tasks 3, 7).
3. **Every event or an explicit error.** On the proxy pod: a sequence check after the snapshot. Upstream failure means a re-read, then a final event or `TASK_STREAM_INTERRUPTED`. There is never a silent end (Task 11).
4. **No stage blocks another subscriber.** Publishing uses `TryWrite`. There is one bounded channel per subscriber on the runner and one per client on the proxy. Each proxied subscription has its own HTTP/2 stream (Tasks 2, 11).
5. **Durable cancel.** The flag is set by a conditional update. The runner polls it. The sender waits with a bounded backoff. A "no live runner" cancel claims the task first (Tasks 3, 9, 10).
6. **Internal port isolation.** The internal endpoints answer only on `InternalPort` (`RequireHost`). The public port gives 404. A request without valid pod credentials gives 401 and is never executed (Tasks 7, 8, 17).

## Plan's calls (decisions this plan makes where the spec is open)

Each one is marked "plan's call" in its task, and listed in the PR description.

1. **Per-event sequence on the runner pod (Task 3).** The handler's stream yields `StreamResponse` only, but the proxy needs each event's task `Sequence` (spec §7.7). `A2ACallContext` gets a public `Action<long>? EventSequenceObserver { get; init; }`. `TaskManager` calls it with each event's sequence, just before it yields that event on subscribe and streaming-send paths. The internal endpoint sets it, and reads the last value after each `MoveNextAsync`. This is safe because only tracing (a 1:1 wrapper) runs on forwarded calls. The event bus delivers `SequencedEvent(long Sequence, StreamResponse Event)` internally.
2. **`ClusterCallContext` mapping is public on the type (Task 4):** `ClusterCallContext.From(A2ACallContext)` and `ClusterCallContext.ToCallContext()`. This way 07's `ReducedCaller` stays internal (07 plan note 3), and the Cluster package needs no internals. The caller travels as 05's public `StoredCaller`.
3. **Distributing-bus detection (Task 1).** `ITaskEventBus` gets a default-implemented property `bool DistributesAcrossInstances => false`. The startup check in spec §7.3 ("must not be replaced by a backend that already distributes events, if HTTP forwarding is also on") reads it.
4. **The subscribe error while a task is being recovered (Task 3).** The spec says "task is being recovered, resubscribe" but names no reason. The plan uses `InternalError` with ErrorInfo reason `TASK_STREAM_INTERRUPTED` and the message "The task is being recovered. Call SubscribeToTask again.", because package 10 already resubscribes on that reason.
5. **`SUBSCRIBER_TOO_SLOW` message (Task 2):** "The subscriber fell behind the task's events. Call SubscribeToTask again." The spec names the reason only.
6. **The internal listener needs explicit Kestrel endpoints (Task 5).** Adding a listener in code overrides `ASPNETCORE_URLS`. So `AddA2ACluster()` fails at startup unless the app uses `ConfigureA2AKestrel()` (09) or configures Kestrel endpoints itself. The message names both options.
7. **`kind` cluster image (Task 19).** `SharedKey` must not ship (C6), and `kind` has no Entra. So the nightly `kind` cluster job runs a test-only host image, `tests/Ambinder.A2A.Cluster.KindHost`: the sample agents, the EF PostgreSQL store, and `SharedKey` pod auth. The real-AKS job uses the sample with `AddEntraPodAuthentication()`.
8. **TCK round-robin proxy (Task 18)** uses `Yarp.ReverseProxy` in test code only (HTTP/1.1, HTTP/2 and gRPC trailers), with a random load-balancing policy.

```csharp
namespace Ambinder.A2A.Server.Cluster;

public interface ITaskEventBus
{
    // Never blocks the caller. Called under the task's local lock, after the store write.
    void Publish(TaskKey task, long sequence, StreamResponse evt);
    // Registers now, before returning, so no event published after the call is missed.
    TaskSubscription Subscribe(TaskKey task, SubscriptionOptions options, CancellationToken ct);
    /// <summary>True when events published on one instance reach subscribers on other instances (for example Redis). Plan's call 3.</summary>
    bool DistributesAcrossInstances => false;
}

public readonly record struct SequencedEvent(long Sequence, StreamResponse Event);   // plan's call 1

public abstract class TaskSubscription : IAsyncDisposable
{
    public abstract IAsyncEnumerable<StreamResponse> ReadAllAsync(CancellationToken ct);
    /// <summary>The same events with their task sequence. Default: not supported (plan's call 1).</summary>
    public virtual IAsyncEnumerable<SequencedEvent> ReadSequencedAsync(CancellationToken ct) => throw new NotSupportedException("This event bus does not report sequences.");
    public abstract ValueTask DisposeAsync();
}

public sealed record SubscriptionOptions
{
    public int Capacity { get; init; } = 256;       // TaskEventBroker.cs:64-69 today
}

public interface ITaskRouter
{
    ValueTask<TaskRoute> RouteAsync(StoredTask task, A2AOperation operation, ClusterCallContext call, CancellationToken ct);
}

public enum TaskRouteKind { Local, Forward }
public readonly record struct TaskRoute(TaskRouteKind Kind, PeerInstance? Peer)
{
    public static TaskRoute Local { get; } = new(TaskRouteKind.Local, null);
}
public sealed record PeerInstance(string InstanceId, Uri InternalAddress);

public interface ITaskForwarder
{
    ValueTask<AgentTask> CancelAsync(PeerInstance peer, ClusterCallContext call, CancelTaskRequest request, CancellationToken ct);
    IAsyncEnumerable<StreamResponse> SubscribeAsync(PeerInstance peer, ClusterCallContext call, SubscribeToTaskRequest request, CancellationToken ct);
    ValueTask<SendMessageResponse> SendAsync(PeerInstance peer, ClusterCallContext call, SendMessageRequest request, CancellationToken ct);
    IAsyncEnumerable<StreamResponse> SendStreamingAsync(PeerInstance peer, ClusterCallContext call, SendMessageRequest request, CancellationToken ct);
}

public sealed record ClusterCallContext
{
    public required string Agent { get; init; }
    public required string Tenant { get; init; }                    // "" when none (05/07)
    public string? ProtocolVersion { get; init; }
    public IReadOnlyList<string> RequestedExtensions { get; init; } = [];
    public string? Transport { get; init; }
    public required StoredCaller Caller { get; init; }              // 05's reduced caller (B8); never a token
    public string? RequestId { get; init; }
    public string? TraceParent { get; init; }
    public string? TraceState { get; init; }
    public int HopCount { get; init; }
}
```
