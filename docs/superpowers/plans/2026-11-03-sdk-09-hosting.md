# SDK 09 Hosting on AKS: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task by task. Every subagent runs on model `sonnet` (see "Execution notes"). Steps use checkbox (`- [ ]`) syntax for tracking.

**Milestone:** M1. The rolling-restart acceptance test moves to M2 with package 06 (B1).

**Goal:** Make one pod production-ready on AKS. This means:

- one gRPC port for all agents
- public URLs that do not depend on bind ports
- the `IA2AMiddleware` pipeline around every operation
- graceful shutdown and crash recovery
- SSE heartbeats
- limits and rate limiting
- health checks, TLS and forwarded headers
- per-request agent cards and route layouts
- a single-replica AKS sample tested on `kind`

**Architecture:**

- `Ambinder.A2A.Server` (core, no ASP.NET Core) gets:
  - the middleware pipeline: `IA2AMiddleware`, `A2APipelineRequestHandler`
  - the execution host: `AgentExecutionHost`, limits, shutdown, recovery
  - instance identity and per-request card types
- `Ambinder.A2A.AspNetCore` gets:
  - route layouts, SSE heartbeats, card variants
  - rate limiting, health checks, forwarded headers, TLS, Kestrel helpers
  - shutdown wiring
- `Ambinder.A2A.AspNetCore.Grpc` gets `AddA2AGrpc()`, `MapA2AGrpc()` and gRPC agent routing by request `tenant` or host.
- `deploy/aks/` holds Kustomize manifests. A `kind` CI job applies them.

**Tech stack:**

- .NET 10 and ASP.NET Core
- `Microsoft.Extensions.Hosting.Abstractions`
- ASP.NET Core rate limiting, health checks and forwarded headers
- `Grpc.AspNetCore`
- `Microsoft.Extensions.TimeProvider.Testing` (`FakeTimeProvider`)
- `Microsoft.AspNetCore.TestHost`
- xUnit v3
- Kustomize, `kind`, Gateway API with Envoy Gateway in CI

**Spec:** `docs/superpowers/specs/2026-11-03-sdk-09-hosting-design.md` (approved 2026-11-03).

**Binding inputs:**

- the work plan `2026-11-03-sdk-00-work-plan.md`, including B1, B2, B4, B5, B8, B13 and C10
- package 01's package map (`2026-11-03-sdk-01-packaging-release-design.md` §1)
- the interacting parts of specs 03 (D5, D7, version check), 05 (§7.2, §7.3, §7.5, §7.8), 06 (§ forwarded calls, recovery, shutdown), 07 (caller, tenant, authorization middleware, rate-limit key) and 11 (`AgentOptions`, `Recovery`, extension step)

## Global constraints

- **No code outside this package's scope.** Do not change 05's store contract, 07's auth types, 03's version check or 08's push code beyond the call sites named here.
- **Assemblies follow 01's map.** Pipeline, execution host, limits options, recovery, instance identity and card request types go in `Ambinder.A2A.Server`, with no ASP.NET Core reference. HTTP, SSE, rate limiting, health, forwarded headers, Kestrel and TLS go in `Ambinder.A2A.AspNetCore`. gRPC goes in `Ambinder.A2A.AspNetCore.Grpc`. Run 01's dependency allow-list test after any `csproj` change.
- **Public API files.** If package 02 has landed, every new or changed public member goes into that project's `PublicAPI.Unshipped.txt` in the same commit, and the build must pass. If 02 has not landed, skip this.
- **More package 02 rules** (`docs/superpowers/plans/2026-11-03-sdk-02-public-api.md`; 02 may land before or after this plan):
  - **No positional public types.** The only positional public types in the SDK are the six package 05 key structs (owner rule, 2026-11-03). `AgentCardRequest` (spec 09 now shows it this way), `AgentRecoveryInfo`, and the harness's `TaskEvent` use `required` / `init` properties. Build them with object initializers.
  - **No `InternalsVisibleTo` between shipped assemblies.** Code in `Ambinder.A2A.AspNetCore` and `Ambinder.A2A.AspNetCore.Grpc` uses only public types of `Ambinder.A2A.Server`. A small pure helper both need goes to `src/Shared/` as a linked internal file (spec 01 rule 10). `InternalsVisibleTo` to the matching `*.Tests` project and to `Ambinder.A2A.Integration.Tests` is allowed (owner decision 2026-11-03).
  - **XML docs:** `<remarks>` with lifetime and concurrency on every implementer-facing interface and abstract type (`IA2AMiddleware`, `IGrpcAgentRouter`, `IA2AShutdownParticipant`, `RecoveryPolicy`), and the "More values can be added in later versions; handle unknown values." remark on every public enum (`A2AOperation`, `GrpcRouting`, `AgentCardKind`, `CardVariesBy`, `A2ARouteLayout`, and the harness's `A2ABinding`).
  - **Logging:** `[LoggerMessage]` with fixed `EventId`s in the assembly's plan 02 block: `Ambinder.A2A.Server` 1000–1999, `Ambinder.A2A.AspNetCore` 2000–2999, `Ambinder.A2A.AspNetCore.Grpc` 3000–3999 (unless `docs/policies/versioning.md` lists another scheme).
  - **JSON metadata:** code outside `Ambinder.A2A.Protocol` never uses `A2AJsonContext`; use the `A2AJson` typed accessors.
  - **Breaking-change records:** each removed or replaced Phase 1 public member (for example `ConfigureA2AKestrel` and gRPC-by-port, `TracingRequestHandler`) gets a "Breaking changes" line in `CHANGELOG.md` and a row in `docs/migration/phase1-map.csv`, unless package 02 already recorded it.
- **`TimeProvider` only.** No `DateTime.UtcNow`, `DateTimeOffset.UtcNow`, `Task.Delay`, `Thread.Sleep`, `new PeriodicTimer(...)` or `System.Threading.Timer` in `src/`. Use the DI `TimeProvider` (`TimeProvider.CreateTimer`, `GetUtcNow`, `Task.Delay(TimeSpan, TimeProvider, CancellationToken)`). The one documented exception is ASP.NET Core rate limiters' own clock (spec §7.6).
- **Tests (B2):**
  - No new test uses a fixed port. Kestrel tests listen on port `0` and read the bound address.
  - No new test uses `Task.Delay` or `Thread.Sleep` to wait. Use `FakeTimeProvider.Advance`, `TaskEventLog` waiters, `TaskCompletionSource` signals, or reading a child process's stdout.
  - Each test that awaits a waiter passes a timeout of at most 10 s of real time. The timeout guards against a hang. It is not a wait.
  - One exception: a negative check ("nothing was written yet") may read with a real timeout of at most 100 ms (Task 12).
- **Errors say what to do** (principle 3). Every startup failure message names the option to change. The spec's exact messages are quoted in the tasks. Copy them verbatim.
- **Development needs no config.** `dotnet run` of the getting-started sample works with no hosting settings (spec §8.3).
- **Build rules:** `TreatWarningsAsErrors`, nullable on, central package versions in `Directory.Packages.props`. Library floors are `10.0.0` for Microsoft packages (01 rule 7). Tests use the newest versions.
- **Commits:** one commit per task at least. Messages are in the imperative and plain. Every commit ends with the attribution lines the session gives you.
- **Run tests:** `dotnet test Ambinder.A2A.slnx -c Release` before each commit. A test filter is fine while iterating, but run the full suite before the commit.
- **Docs style:** short plain English sentences, the repo style.

## Review focus (reviewers check these first)

1. **The pipeline cannot be skipped.** No transport, and no 0.3 dispatcher, calls `TaskManager` directly. In-process `IA2ARequestHandler` resolves to `A2APipelineRequestHandler` (Tasks 3–5).
2. **Streams.** A middleware throw before the first event gives a plain error response. A throw after it gives an error frame. Heartbeats never interleave with a frame (Tasks 5, 12).
3. **Shutdown arithmetic.** `DrainDelay + ExecutionGracePeriod + 3 s ≤ HostOptions.ShutdownTimeout` is enforced at startup. Nothing is left `WORKING` with a live runner after stop (Task 19).
4. **Recovery never re-runs an agent that did not opt in** (`Fail` default; `[IdempotentAgent]` gives `Restart(1)`; explicit option wins) (Task 20).
5. **No trust-all.** Forwarded headers are ignored from untrusted addresses. Hosts outside `AllowedPublicHosts` never reach a card URL (Tasks 9, 10, 16).
6. **No server code reads `Connection.LocalPort`** (Task 8 source test).

Sweep, on start (immediately) and then every `RecoveryInterval` (`TimeProvider` timer):

1. `now = time.GetUtcNow()`. `expired = instances.ListExpiredAsync(now - ClockSkewAllowance)`.
2. For each expired instance:
   - Page `tasks.ListByRunnerAsync(id, max: 100)` until empty.
   - Claim each task with `UpdateAsync(write, task.Version)`:
     - `Fail`, or `Restart` with attempts used up (`RunAttempt >= maxAttempts`): set state `FAILED` with the documented message and `Runner = null`.
     - `Restart`: set `Runner = (self, now)`, `RunAttempt + 1`, and `LastRunnerInstanceId` = the dead id. Then start the run on `AgentExecutionHost` with `AgentRequestContext.Recovery = new(Attempt: RunAttempt + 1, PreviousInstanceId: deadId)`. The run's caller is rebuilt from `task.Caller` (07; no token, B8). The message is the last user message in history.
   - `A2AStoreException(Conflict)` means another pod claimed it. Skip, and log at Debug.
   - If an expired instance has no tasks left, delete its lease row (`DeleteAsync(id, lease.Version)`).
3. Released tasks: `tasks.ListReleasedAsync(now - LeaseDuration, limit: 100)`. Apply the same claim and policy (B4).
4. Recovered runs take execution slots like any run. If none is free, skip the task this round (do not fail it). Log Information "Recovery deferred: server busy".

Fencing comes from 05's writer rule (§7.10): a write by a run whose `Runner` changed hits `Conflict`, and the run is stopped. Add a test, but no new code.
