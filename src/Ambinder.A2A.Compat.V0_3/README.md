# Ambinder.A2A.Compat.V0_3

A2A 0.3 compatibility for the [Ambinder.A2A](https://github.com/roman-ambinder/a2a-starter#readme) client. With this package the normal `IA2AClient` calls agents that still speak A2A 0.3 over JSON-RPC, REST and gRPC. The 0.3 models and converters are internal; the public API is one registration method.

```
dotnet add package Ambinder.A2A.Compat.V0_3
```

Package status: skeleton. The client adapters arrive in later tasks of the package 15 plan.

The server side is [Ambinder.A2A.Compat.V0_3.AspNetCore](https://www.nuget.org/packages/Ambinder.A2A.Compat.V0_3.AspNetCore).

Part of [Ambinder.A2A](https://github.com/roman-ambinder/a2a-starter#readme): see the repository for samples and guides.
